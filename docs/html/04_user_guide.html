Getting started
1
Upload your resume (PDF, DOCX, or TXT) — the extracted text appears in an editable box so you can review or add details before running.
2
State a career goal for a full roadmap, or leave it blank for a market-position analysis only.
3
Click Run analysis and watch the live status panel as the orchestrator delegates to each subagent in sequence.

Reading a result
Risk dashboard
Five scores (0-10 each): salary, skill, security, burnout, growth risk — validated in code, not self-reported by the model.
Human approval gate
Before any calendar-sync action, the run pauses and shows exactly what it wants to do. Approve or reject — nothing is synced without your decision.
Limits, honestly stated
What it won’t do. Without a LinkUp or Tavily key it falls back to grounding-only market facts — still honest, but not live. The calendar sync is simulated; nothing is ever actually written to a real calendar. Salary and timeline estimates are grounded projections, not guarantees — always sanity-check a major decision against current, specific offers.
Best practices
  • Upload a complete resume rather than a short summary — profile-analyzer works from whatever text it receives.
  • State a specific, time-bound goal (“₹100L in 2 years”) rather than a vague one (“more money”) so the recommender can compute a real gap.
  • Review the extracted resume text box before running — fix any parsing gaps first.
  • Treat a long run time (several minutes) as normal, not a hang — the live status panel shows which subagent is currently working.
