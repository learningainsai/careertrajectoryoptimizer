Prerequisites
Python 3.12+
A working interpreter; the project ships a pyproject.toml managed by uv.
uv
Handles the virtual environment and locked dependency installs via uv sync.
OpenAI API key
Required — the orchestrator and every subagent call this model.
LinkUp or Tavily key (optional)
Enables market-researcher’s live web search; omit both to run grounding-only.

Troubleshooting
OPENAI_API_KEY missing
The Streamlit sidebar shows a red status and blocks the agent from building; add it to .env and refresh.
A run takes 5+ minutes
Expected — 6 to 9 subagents each run their own multi-turn loop. Career Aspiration Mode and the calendar-sync HITL gate add more time.
A single call stalls for minutes
Likely a per-minute rate limit; the model is bounded to max_retries=2, timeout=60s so it fails fast and visibly instead.
Resume text looks incomplete
Many resumes lay out skills/experience in tables — the extractor walks the whole document (paragraphs + nested tables) to avoid missing them.
Ready to run in about 10 minutes.
No infrastructure to stand up — the store, checkpointer, and backend are all in-process; only your API keys are external.
