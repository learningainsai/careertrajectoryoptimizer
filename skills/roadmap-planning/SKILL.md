# Roadmap Planning

## When to use
Only in Career Aspiration Mode, after the gap analysis is available, to produce the
final personalized roadmap.

## Structure
1. **Goal summary** — restate the goal in one line (salary, role, company, timeline).
2. **Gap analysis** — skills, salary, and experience gaps versus the goal.
3. **Upskilling plan** — courses (with time/cost/ROI), portfolio projects,
   certifications if relevant, and a networking plan (target companies/people).
4. **30-60-90 day plan**:
   - Month 1: learn and position
   - Month 2: decision point (stay and grow, or start switching)
   - Month 3: execute
5. **Timeline to goal** — a realistic estimate, not the most optimistic one.
6. **Salary projection** — current to goal, with milestones.
7. **Success probability** — a percentage, with the reasoning behind it stated plainly.

## Rules
- Every recommendation must trace back to the gap analysis — no generic advice.
- Timelines must be realistic; flag when a goal's timeline looks unrealistic instead of
  silently agreeing with it.
- Keep the plan actionable: each month must have concrete, checkable tasks.
